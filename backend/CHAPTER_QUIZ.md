# 章节测验适配范围

当前界面进入课程只读取章节目录，并显示目录已有的完成标记、待完成任务点数及课程总进度；状态不明时保留未知，点击“重读目录”刷新。点击“一键学习所选章节”后，按目录顺序逐章读取卡片。`workid` / `work` 是章节测验，文档和其他附件单独统计，不再统称“其他任务”。独立作业列表和考试不由此入口执行。

“自动提交章节测验”默认勾选，“随机选择选项”默认不勾选。默认采用与作业相同的答案策略：选择题按题干、类型和选项正文查询本地题库，未命中调用 DeepSeek；简答题直接生成，不查题库。当前登录用户在所有课程、章节测验和作业中共用同一 SK、题库与 DeepSeek 配置（`deepseek-flash` / V4.1-Flash-1017、思考 low）；SK 加密保存、重启恢复，不跨用户共享，退出时清除。配置说明见 [HOMEWORK.md](HOMEWORK.md)。

勾选“随机选择选项”后完全绕过题库和 DeepSeek：保留页面已有的有效作答，没有已有作答时，从页面实际选项中随机选一个，再正式提交。随机模式不生成简答。取消“自动提交章节测验”会跳过测验并标记部分完成。两种答案策略均不保证正确或通过，默认策略失败不会自动改用随机答案。

## 来源与实现

- 章节入口参数依据已保存的官方 [work 模块源码](https://mooc1.chaoxing.com/ananas/modules/work/index.html)。从实际卡片 iframe 的 JSON `data` 读取模块标识，同时识别 work 模块的 `src` 与懒加载的 `module="work"` 标识；懒加载 iframe 可以没有 `src`。从当前卡片及学习页读取平台下发的凭证，构造学生模式 `/mooc-ans/api/work` 请求。不会推导或复用其他课程的签名；同一任务必须唯一匹配模块。
- 答题表单支持原有 `submitForm/questionLi`，以及在军事理论实际观察到的 `form1/TiMu` 模板。后者仅在章节测验入口启用，多选选项同时识别 `num_option_dx`。序列化依据页面 `confirmSubmitWork` 和 `version` 源码，使用浏览器表单实际控件与字段，课程、班级、章节、cpi、任务标识均需核对一致。提交目标必须是同一主机下的 `/mooc-ans/work/addStudentWorkNewWeb`；相对 action 会基于当前答题页解析。
- 支持实际选项结构符合已知格式的单选、多选，以及实际选项明确给出 `true` / `false` 的判断题。默认策略支持已识别的 type=4 简答控件；随机模式的空白多选也只选一个实际选项。填空、复合题或其他未知结构不生成答案，也不提交整个测验；同章其余任务继续处理。`font-cxsecret` 内嵌 TrueType 字体先在本地按字形映射解码，再查询题库或交给模型；缺失字体、无法识别的字形、图片或未知结构会显示具体原因。实现和映射来源见 [FONT_DECODING.md](FONT_DECODING.md)。
- 读取同一个持久提交记录后先核对已有结果，不重复调用模型或 POST。SK 缺失、失效、额度、限流和网络问题停止整个队列，不继续打开下一章；未知题目或无效答案不提交当前测验。题库命中、DeepSeek 生成与简答生成数分别显示。
- 保留服务端隐藏字段和签名，使用原有 `answer{qid}`、`answertype{qid}`、`answerwqbid`、`pyFlag` 及版本字段。提交前校验要求 `/mooc-ans/work/validate` 返回数值 `status=3`。其他状态、提交验证码和人脸/插件要求交给原网页处理。
- POST 只发送一次，不跟随跳转、不自动重试。每个作答实例在写入前创建持久提交记录，仅保存身份哈希、时间、数量和状态，不保存 Cookie、签名、题目或答案。结果不明、记录损坏或平台拒绝后，后续启动不会自动重复提交。
- `form1` 的查询字段保留平台原 action 中的凭证和参数，按原页面递增版本；页面 `getEnc()` 不可用时按源码的 catch 分支使用空 `pos`，不生成定位等信息。这个模板的暂存接口与正式提交不同，目前不开放其草稿暂存。服务器要求额外验证时仍停止处理。
- 业务响应 `status=true` 只计入“本次接受提交的测验”；再读取原卡片，匹配任务标识且 `isPassed=true` 才计为通过。未通过不自动重新随机作答。

## 验证边界

已完成离线协议、模拟传输、队列和浏览器界面验证。2026-10-26 只读核对军事理论的“国防的内涵”“国防的职能与使命【上】”“国防的中立类型”页面，实际读取到上述懒加载 iframe 与 `form1/TiMu` 模板；对“国防的中立类型”的三题生成表单请求但未发送。真实平台未做正式提交验证，没有确立所有章节测验都使用同一种表单。未知模板、提交验证码和特殊流程仍明确列为需要处理。
