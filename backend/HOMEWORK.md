# 作业标题列表与一键提交

进入课程后选择“作业”。页面显示作业标题、选择框与服务器列表的完成状态；读取列表时不打开答题页。“全选作业”仅选择已确认未完成且当前可提交的作业，排除已提交、待批阅、已截止和未开放项目；状态未知可手动选择。点击“刷新作业”更新状态。列表 API 额外返回 `isCompleted`（布尔或 null）和 `statusText`（已识别的状态标签），不返回平台签名链接。

勾选作业并点击“一键提交所选作业”后，后端按列表顺序逐份打开详情、获取答案、校验并正式提交。不提前读取下一份作业详情。原已提交或未开放的作业不可选择，启动时重新核对服务器列表。

## 答案策略

- 单选、多选、判断题：按题型、题干和选项正文查本地题库，未命中才请求 DeepSeek。按选项正文映射当前标签，避免选项顺序改变导致串答。已有作答不作为正确答案来源，作业模式不使用随机答案。
- 简答题（已观察的 type=4 控件）：直接请求 DeepSeek，不查询或缓存题库，不沿用旧作答。生成的纯文本转义后写入实际 `answer{qid}` 控件。
- 图片、公式/媒体、填空、复合题、未知编辑器或无法解析的题目不自动提交该份作业。需要同一作业全部题目可识别且答案完整、合法；不会提交部分答案。
- DeepSeek 生成的选择题答案缓存为来源 `deepseek`，仅表示模型生成及选项校验通过，不代表经老师批改证实正确；不会把提交接受等同于答对。

## DeepSeek 配置

在章节或作业页面下方填写自己的通用 SK，可点击“保存 SK”，也可填写后直接启动，程序先保存再启动任务。同一登录用户的所有课程、章节测验与作业共用此配置，任一入口保存或清除后同步生效；原先在作业页保存的 SK 无需再填。清除 SK 后，如果选择题全部命中题库，仍可提交；有未命中题目或简答题则需要有效 SK。SK 无效、余额不足、限流或网络故障会停止队列，后续作业不再打开详情。

核对官方文档时间为 2026-10-26。请求固定使用：

```json
{
  "model": "deepseek-flash",
  "thinking": {"type": "enabled"},
  "reasoning_effort": "low",
  "response_format": {"type": "json_object"},
  "max_tokens": 16384,
  "stream": false
}
```

官方 `deepseek-flash` 当前对应 DeepSeek-V4.1-Flash-1017，最低思考档为 low。参考：[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。模型别名以服务商实际路由为准，后续服务商可能更新版本。

固定目标为 `https://api.deepseek.com/chat/completions`，禁止跟随重定向。仅发送题号、题型、题干及实际选项，不发送超星 Cookie、课程链接、课程令牌、作答实例或表单签名。SK 只放在该请求的 Authorization 中。每批最多 10 题，无自动 API 重试；无法解析、截断、题目集合不一致或无效选项时不提交。返回的思考过程不入库、不展示。

SK 按当前登录会话隔离，随用户登录凭证加密保存在数据目录；重启可以恢复。接口只返回是否已配置，不返回 SK。管理列表、任务记录和日志不含 SK。主动退出或会话过期删除可恢复凭证；待确认二维码不带 SK。真实 API 调用会产生服务商用量费用，界面有说明。

## 本地题库

数据保存在 `data/question-bank.sqlite3`，按当前登录会话隔离，关闭浏览器或重启后端后保持。题库内容包括题干、选项正文、所选答案及来源，不包含平台凭证。主动退出后新建登录会话不共享旧会话题库，可在退出前导出，下一次登录重新导入；不同前端用户不能读取彼此的题库。

作业页面提供导入、导出和格式示例。导入 JSON 结构：

```json
{
  "questions": [
    {
      "type": "0",
      "text": "一加一是多少？",
      "options": [{"label": "A", "text": "二"}, {"label": "B", "text": "三"}],
      "answer": "A"
    }
  ]
}
```

题型：`0` 单选、`1` 多选（如 `AC`）、`3` 判断（选项标签须为 `true/false`）。简答题不导入题库。题干和选项正文应与页面一致，不包含题目编号及题型/分数说明；程序做 Unicode 和空白标准化，不做模糊匹配。相同正文的重复选项会拒绝匹配。每次导入最多 1000 道选择题，界面文件上限 1.9 MB。

## 提交及验证边界

使用课程主页下发的作业菜单和 `workEnc` 读取列表，按已观察的列表脚本处理分页。详情入口必须来自当前列表行，课程、班级和 cpi 均核对一致；表单进一步核对 workRelationId、作答实例、实际选项、唯一控件和同一主机的正式提交目标。提交前 `/work/validate` 仅接受数值状态 3；验证码、人脸和特殊平台流程在原网页处理。

正式 POST 只发送一次、不跟随跳转、不自动重试。在发送前创建仅含哈希身份、时间和题目数的持久记录；接受、拒绝或结果不明的作答实例都不会自动重交。提交响应接受和重新读取列表确认完成分开计数；不推断成绩。停止操作会等待当前网络调用结束，DeepSeek 单次超时最长 120 秒；此后不打开下一份作业或提交新答案。重启不恢复运行任务。

一次最多选择 100 份作业，一份最多自动处理 200 题。模板不同或验证失败时明确提示。独立考试不由本入口执行；章节内测验仍使用章节流程的设置。

实现验证使用受控网络适配器、合成题目和模拟 DeepSeek 响应，不消耗真实 API 额度、不提交真实作业。已有真实作业页样本的 20 道选择题可提取结构化题干和选项；军事理论当前独立作业列表为空，此项仅做只读验证。没有用户实际 SK，因此不宣称完成真实模型调用与真实作业提交的本轮闭环验证。
